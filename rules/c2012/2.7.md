---
rule_id: c2012-2.7
title: Funktions-Parameter sollen tatsächlich verwendet werden
---

Ungenutzte Funktions-Parameter sind ein Hinweis auf veraltete
Schnittstellen oder vergessene Implementierungs-Pfade. Entweder die
Signatur reduzieren oder den Parameter sichtbar als unbenutzt
markieren (z.B. via `(void)param;`-Cast), damit Reviewer und
Compiler den Befund nicht für einen Implementierungs-Bug halten.

```c
/* unsauber — Parameter erscheint relevant, ist es aber nicht */
int handle_event(int code, int unused) {
    return code * 2;
}

/* OK — Absicht der Nicht-Verwendung dokumentiert */
int handle_event(int code, int unused) {
    (void)unused;
    return code * 2;
}
```
